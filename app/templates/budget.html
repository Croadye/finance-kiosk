How to use Budget

Planned: the monthly cap you set for each category.

Spent: adds up all expenses (negative amounts) posted to that category this month.

Available = Planned − Spent. If it goes red, you’re over budget.

  • Use the Planned inputs to set caps and click Save Budget.
  • Record purchases via + Add → pick the account and category.
  • Change months with the picker (top-right).
